# 🚴‍♂️ Tour d'Autriche – ÖIF A2 Integration Exam Prep

A mobile-first, cycling-themed web game designed to help native English speakers prepare for the **Austrian Integration Exam (ÖIF A2 – Werte- und Orientierungswissen)**.

Built specifically to reduce reading fatigue and language barriers through **audio support, visual anchors, progressive scaffolding, and positive coaching**, the app gradually transitions learners from supported micro-sprints to real German-only exam conditions.

---

## ✨ Key Features

- **Cycling Race Theme ("Tour d'Autriche"):** All 7 official ÖIF knowledge categories are structured as tour stages, complete with XP, career ranks (*Rookie* to *Austrian MVP*), and a visual pacemaker bike bar.
- **Dyslexia- & Beginner-Friendly Scaffolding:**
  - **Built-in German Text-to-Speech (`de-AT`):** Automatic audio playback in Level 1 plus individual speaker buttons on every answer choice.
  - **Visual Anchors:** Emoji/icon cues paired with each question to build direct visual-to-German memory links.
  - **Tap-to-Translate Keywords:** Highlighted German keywords reveal quick English translations on tap without overwhelming the screen.
- **4-Gear Spaced Repetition (Leitner Slot System):**
  - **Slot 1 (Warm-Up):** 0–2× correct (high frequency)
  - **Slot 2 (Tempo):** 3× correct (counts toward Daily Stage Goal)
  - **Slot 3 (Breakaway):** 4–9× correct
  - **Slot 4 (Mastered):** 10+× correct
  - Wrong answers never punish the player—instead, a supportive English **Coach Tip** appears, and the card steps back only one slot so momentum stays high.
- **4 Progressive Race Modes:**
  1. **Level 1 – Training Camp (90s/card):** Single-stage 8-card sprints with full audio, visual anchors, and English keyword pop-ups.
  2. **Level 2 – Time Trial (90s/card):** Mixed stages, English removed, optional visual hints on tap, manual audio.
  3. **Level 3 – Cadence Sprint (60s/card):** High-speed training with official German exam text, bolded signal words, and 2/3-point scoring.
  4. **Level 4 – World Championship (Official ÖIF Exam Simulation):** 18 mixed questions (9× 2-point + 9× 3-point, no duplicate variants), 40-minute exam clock, pure German text, and a 25/45-point passing threshold.
- **Zero-Backend & Offline-Friendly:** Runs in a single HTML file using browser `localStorage` to save progress automatically on any smartphone.

## 📚 Covered ÖIF A2 Stages (171 Questions)

1. **Allgemeines Orientierungswissen** (Austrian Geography, Politics & Facts)
2. **Stellenwert von Sprache und Bildung** (Education System, Apprenticeships & Equality)
3. **Arbeitswelt und Wirtschaft** (Work, Taxes, Net vs. Gross Salary & AMS)
4. **Gesundheit** (Healthcare System, e-card & Emergency Numbers)
5. **Wohnen und Nachbarschaft** (Renting, House Rules, Quiet Hours & Recycling)
6. **Rechtliche Integration** (Rule of Law, Democracy, Safety & Freedom of Speech)
7. **Kulturelle Integration** (Religious Freedom, Family, Diversity & Volunteering)

## 🚀 How to Run & Host

### Run Locally
Simply double-click `index.html` to open the app in any modern web browser (Chrome, Safari, Edge, Firefox).

### Host Free via GitHub Pages
1. Push this repository to GitHub as a **public** repository.
2. Go to **Settings → Pages** in your repository.
3. Under **Build and deployment → Branch**, select `main` and `/ (root)`, then click **Save**.
4. Open the generated GitHub Pages URL on your smartphone and tap **"Add to Home Screen"** for a full-screen app experience.
